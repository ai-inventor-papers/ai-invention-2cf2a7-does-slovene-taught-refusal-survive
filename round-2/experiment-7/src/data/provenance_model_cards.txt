# GaMS-Nemotron-Chat

**GaMS-Nemotron-Chat** is a conversational dataset containing approximately 98,000 examples, designed to improve the instruction-following and conversational capabilities of Slovene language models. It is derived from the [Nemotron Post Training Dataset v1](https://huggingface.co/datasets/nvidia/Nemotron-Post-Training-Dataset-v1), featuring responses generated by the *Qwen3 235B A22B* model. The examples are translated into Slovene using the **GaMS-27B Instruct** [model](https://huggingface.co/cjvt/GaMS-27B-Instruct).

Based on this dataset we finetuned the [GaMS-9B-Instruct-Nemotron](https://huggingface.co/cjvt/GaMS-9B-Instruct-Nemotron) and [GaMS-27B-Instruct-Nemotron](https://huggingface.co/cjvt/GaMS-27B-Instruct-Nemotron) models which as of January 2026 take the 4th and 2nd spot on the Slovenian Chat Arena ([see the current leaderboard here](https://arena.cjvt.si/en/leaderboard)).

## Dataset Description

The dataset focuses on structure, formatting (Markdown), and detailed explanations. It follows an **80:20 split** between translated Slovene examples and original English examples to maintain multilingual capabilities and prevent language degradation.

- **Total Examples:** ~98,000
- **Languages:** Slovene (80%), English (20%)
- **Source:** Subset of LMSYS Chat 1M (via Nvidia Nemotron)
- **Filtering:** Filtered using MinHash LSH and length-ratio checks.

## Dataset Structure

Each example in the dataset contains the following fields:

| Column | Type | Description |
|:---|:---|:---|
| `conversation_id` | `string` | Unique identifier for the conversation, inherited from the source. |
| `prompt` | `list` | The user's input message(s). For Slovene examples, this is the translation of the original [LMSYS Chat 1M](https://huggingface.co/datasets/lmsys/lmsys-chat-1m) user prompt. |
| `completion` | `list` | The assistant's response. Sourced from Qwen3-235B generations (via Nemotron), translated to Slovene, or regenerated for identity correction. |
| `ds_name` | `string` | The name of the source dataset (e.g., `nvidia/Nemotron-Post-Training-Dataset-v1`). |
| `ds_split` | `string` | The split from the source dataset (e.g., `chat`). |
| `language` | `string` | Language code: `sl` for Slovene entries (translated from English), `en` for English entries. |
| `category` | `string` | The topic category of the conversation (e.g., `explanation`, `coding`, `creative writing`), derived from the [LMSYS Chat 1M Clean](https://huggingface.co/datasets/OpenLeecher/lmsys_chat_1m_clean) taxonomy. |
| `identity` | `bool` | Indicates whether the response was specifically regenerated to correct the model's identity (changing "Qwen" to "GaMS"). |

## Creation Process

1.  **Source Selection:** We leveraged the `LMSYS Chat 1M` subset of the `Nemotron Post Training Dataset v1`, where responses were generated by **Qwen3 235B A22B**.
2.  **Filtering:** We applied MinHash LSH filtering (threshold 0.65) on the `LMSYS Chat 1M Clean` subset to select ~80,000 diverse and high-quality examples across various categories.
3.  **Translation:** The selected examples were translated into Slovene using the **GaMS 27B Instruct** model.
4.  **Identity Correction:** Responses where the model identified itself as "Qwen" were regenerated using a custom prompt to establish the **GaMS** identity (`identity` attribute set to True).
5.  **Augmentation:** To support multilingualism, ~20,000 original English examples (non-overlapping) from *Nemotron Post Training Dataset v1* were added to the final mix.

## Datasets and Models Used

### Datasets
- [Nemotron Post Training Dataset v1](https://huggingface.co/datasets/nvidia/Nemotron-Post-Training-Dataset-v1): The source of high-quality responses generated by Qwen3 235B A22B model.
- [LMSYS Chat 1M](https://huggingface.co/datasets/lmsys/lmsys-chat-1m): The source of the original real-world user prompts.
- [LMSYS Chat 1M Clean](https://huggingface.co/datasets/OpenLeecher/lmsys_chat_1m_clean): Used for categorization and filtering of the prompts.

### Models
- **Qwen3 235B A22B**: The model used by NVIDIA to generate the synthetic responses in the Nemotron dataset.
- [GaMS-27B Instruct](https://huggingface.co/cjvt/GaMS-27B-Instruct): The model used to translate the dataset from English to Slovene.
