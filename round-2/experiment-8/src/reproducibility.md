# Reproducibility

Step-by-step instructions to reproduce the results of this artifact (C3 confirmation: does English Heretic
abliteration reach Slovene refusal harder in GaMS3 than in Gemma-3?). This describes **what was actually run**,
including the mid-run deviations (a shared-budget exhaustion and a pod restart) that shaped the final pipeline.

## 0. What you get and where it appears

* `results/analysis.json` — every headline number (`G3` per curve B/A1/A2, verdicts, depth hazard, C5a, MT-noise).
* `results/audit.json` — independent numpy/scipy re-derivation of those numbers + placebos.
* `results/summary_tables.md` — human-readable rendering of both (regenerated by `src/summarize.py`).
* `results/sanity.json` — judge kappa, degeneracy, pairing, chrF, spend.
* `results/figs/*.pdf|png` — five figures (transfer curves, G3 forest, survival, flip rates, C5a).
* `method_out.json` (+ `mini_`/`preview_`) — per-item predictions in the `exp_gen_sol_out` schema.
* `RESULTS.md` — the narrative with the surviving numbers; `README.md` — repo layout.

## 1. Copy the artifact

```bash
cp -r <this folder> ~/exp8 && cd ~/exp8
```
All paths below are relative to the artifact root. Read-only iter-1 dependencies are referenced by absolute path
inside the run volume (`/ai-inventor/aii_data/runs/run_FVi3e3O9CH5I/3_invention_loop/iter_1/...`); `src_iter1_ref/`
is a copy of the iter-1 exp4 code this artifact adapts.

## 2. System, Python, and libraries

* OS: Ubuntu (Linux 6.8). `gcc` is required (Triton compiles a kernel at first generate): `apt-get install -y gcc`.
* Python **3.12.14**. Environment manager: **uv** (the pod is uv-only; `pip` is not in the venv).

```bash
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python -r requirements.lock.txt
```

`requirements.lock.txt` and `pyproject.toml` pin the exact versions installed. Key pins:
`torch==2.14.0+cu130`, `transformers==5.17.0`, `peft`, `bitsandbytes`, `optuna==4.9.0`, `statsmodels==0.15.0`,
`scipy`, `sacrebleu`, `datasets`, `heretic-llm @ git+https://github.com/p-e-w/heretic@3521f8648a0dccf6e12a92666862632235fac7e6`,
`accelerate`, `aiohttp`, `pytest==9.1.1`. The install takes ~8-9 min (torch/CUDA wheels onto a network FS).

## 4. Exact commands, in order

Seed **20260924** everywhere. Hardware actually used: one NVIDIA **L4 (23 GB)** for the first GPU block and, after a
pod restart, one NVIDIA **RTX 4000 Ada (20 GB)** for the resumed GaMS B trials. NF4 4-bit (double quant, bf16 compute).

```bash
# STEP 1-2: data + frozen protocol (CPU + one GPU pass for NLLB MT; ~20 min)
(cd src && ../.venv/bin/python prep_probe.py)
(cd src && ../.venv/bin/python write_protocol.py)      # writes protocol.json + protocol.sha256; git-commit BEFORE any FINAL gen

# STEP 3: per-model GPU block (Gemma first, then GaMS; identical code path). ~1.5-2.5 h per model on the L4.
DL=$(date -u -d "+6 hours" +%s)
.venv/bin/python -u src/gpu_block.py --model gemma_it  --gpu-deadline-epoch $DL --budget 30000 --max-bs 128
.venv/bin/python -u src/gpu_block.py --model gams3_it  --gpu-deadline-epoch $DL --budget 30000 --max-bs 128
# phases per model: checks -> C depth -> A1 lambda -> A2 ablation(+random) -> C5a -> B Heretic trials (29). Resumable per step.

# STEP 4: judge. The frozen primary is gemini-2.5-flash (both models) with gpt-4.1 second family.
./finalize.sh    # idempotent: judge missing ids -> contamination audit -> build_table -> analysis -> audit -> figs -> method_out.json

# T0 unit checks
.venv/bin/python -m pytest -c pytest.ini tests/
```

### Deviation actually taken (both are logged in `results/protocol_amendments.json`, committed before the affected step)

1. **Shared OpenRouter budget exhausted → substitute local judge.** The run's shared OpenRouter budget hit its
   $7 cap (proxy error `aii_run_budget_exhausted`; this artifact spent $1.06) after gemini had labelled all
   Gemma-3 rows but **zero** GaMS3 rows. Because `G3` is a cross-model contrast it needs ONE judge on BOTH models,
   so the substitute primary is a **local open-weight LLM judge** applied identically to every row of both models,
   with the frozen judge prompt verbatim and the label = argmax of the next-token logits over the first token of
   REFUSE/PARTIAL/COMPLY. Two candidates (`Qwen/Qwen3-8B`, `meta-llama/Llama-3.1-8B-Instruct`) are scored on a
   1,000-row Gemma calibration set against the gemini labels; the higher-kappa one becomes primary, the other the
   second family. All gemini labels are kept and co-reported (Gemma-only curves). Commands:
   ```bash
   .venv/bin/python src/judge_local.py --judge qwen3_8b   --set calib
   .venv/bin/python src/judge_local.py --judge llama31_8b --set calib
   .venv/bin/python src/judge_select.py                       # -> results/judge_local/selection.json
   .venv/bin/python src/judge_local.py --judge <primary> --set all      # both models, all rows + trunc64
   .venv/bin/python src/judge_local.py --judge <second>  --set second   # frozen stratified 15% sample
   .venv/bin/python method.py                                # build_table -> analysis -> audit -> figs -> summarize -> method_out.json
   ```
2. **Pod restart mid-GaMS-B.** A server restart killed the GaMS process during Heretic B trial 19 (trials 1-18
   saved). It was resumed with identical code on the RTX 4000 Ada: the stale RUNNING trial was marked FAIL, the
   saved `residual_directions.pt` reused, and TPE start-up indices 19-20 enqueued with Gemma's paired parameters
   (verified: start-up trials 1-20 are parameter-identical across models). n_B stayed 29.

Earlier deviations (throughput fallback F3, GaMS A2 catastrophic F6, prefill length) are in the same amendments
file and in README "Deviations".

## 5. Numbers to expect

`method.py` prints the verdict and `G3` per curve; `results/analysis.json` holds them. The paper's headline is
`analysis.json:verdict` (computed on curve B, the primary) plus the A1 robustness curve, each with a 95% CI and the
pre-registered verdict against m=0.675 and m_local=0.20. `results/audit.json:all_primary_checks_pass` must be true
and its placebos (model-label-swap G3, shuffled-shallow hazard) must be centred at 0. The lexicon and (Gemma-only)
gemini curves are diagnostics, reported alongside but never as the primary readout. Judge substitution means the
absolute `G3` depends on the local judge; the **sign, the verdict, and the B-vs-A1 (dis)agreement** are the claims
that carry, and every one is recomputed from `results/items_final.jsonl` by both `analysis.py` and `audit.py`.
