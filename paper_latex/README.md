# Over-Refusal of Benign Slovene Prompts Survives English De-censoring in Gemma-3-12B

Public web page and paper for the Slovene refusal study.

## Layout

- `index.html` — self-contained web page (GitHub Pages site entry point)
- `interactive.html` — self-contained explorable page (inline data, CSS and JS) built from the run's recorded per-item outputs of Experiments 5, 9 and 14
- `paper.tex` — LaTeX source of the paper
- `paper.pdf` — compiled paper
- `references.bib` — bibliography
- `references.json` — bibliography in JSON
- `figures/` — all figures used by the paper and the web page
  - `fig_sdt_v0.pdf` / `.png` — criterion-shift signal-detection figure
  - `fig_grid_v0.pdf` / `.png` — crossed prompt x reply language refusal grid
  - `fig_dose_v0.pdf` / `.png` — dose-response curves under abliteration
  - `fig_*_spec.json` — figure specifications
- `workspace/` — scratch folder from the LaTeX build (ignored)

## Restoring removed files

No files were marked for deletion. All outputs are text, code, or small images under 10 MB.
